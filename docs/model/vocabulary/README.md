# Vocabulary

The normative value sets a track is tagged with (baseline `0.1.0-draft`). This is a generated, browsable view of the hand-maintained value sets in `data/vocabulary/`.

- **[Dances](dances.md)** — the dance packs (Swing, Blues, Tango, Ballroom, Street Latin, West Coast Swing, Carolina Shag, Early): each dance with its tempo band, aliases, and typical genres.
- **Musical dimensions** — the shared music vocabulary, one page per dimension:
  [Genre](genre.md) · [Mood](mood.md) · [Rhythmic Feel](rhythmic_feel.md) · [Vocality](vocality.md) · [Instrumentation](instrumentation.md) · [Instrument](instrument.md) · [Recording Context](recording_context.md) · [Recording Quality Era](recording_quality_era.md) · [Theme](theme.md) · [Song Form](song_form.md) · [Credit Role](credit_role.md) · [Routine](routine.md)

Deferred dance families (not yet built): Niche.

How a value is used and stored is the [field reference](../../standard/fields/README.md); this page is about the values themselves.
